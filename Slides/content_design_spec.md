# Bayesian Workflow section — content and design specification

## Teaching purpose

Introduce the Bayesian workflow as a progressively enriched loop before the
course applies it to the golf-putting notebooks. The three slides should give
students one stable visual map that answers, in order:

1. What are the main steps?
2. Where do the checks belong?
3. What should we revisit when a check fails?

## Audience and tone

- Short-course learners with mixed statistical backgrounds.
- Academic and instructional, but visually direct rather than text-heavy.
- The diagram carries the explanation; visible prose is limited to the
  interpretive point for each reveal.

## Visual system

- Preserve the existing 16:9 Touying Metropolis theme.
- Use the course orange (`#eb811b`) for the workflow spine.
- Use a quiet blue for validation checks and a darker blue dashed line for
  corrective return paths.
- Use the same node positions on all three slides so additions read as layers
  on one diagram rather than as new diagrams.
- Build the vector diagram in `Slides/diagrams/bayesian_workflow.typ` and import
  it into `Slides/slide_deck.typ`.

## Slide sequence

### 1. The workflow starts with a four-step loop

Reveal Data → Model → Fit → Interpret, then reveal return arrows from
Interpret to Model and Data. Finish with two implications: different
interpretations and iterative experimental design.

### 2. Checks make each transition accountable

Start from the complete spine. Add Prior predictive, Diagnostics, and
Posterior predictive in sequence, together with one short statement of what
each check tests.

### 3. A failed check tells us where to return

Start from the spine plus all checks. Add corrective return paths in sequence:
prior predictive to Model/Data, diagnostics to Fit/Model, and posterior
predictive to Model/Data. Pair each reveal with its modeling implication.

# Golf-putting model comparison — content and design specification

## Teaching purpose

Turn the abstract workflow into a concrete sequence: establish an honest
prediction task, fit a deliberately simple baseline, replace it with a
scientifically motivated geometric model, and test that model on genuinely
new data. The sequence stops before the discrepancy models so that learners
can see why model expansion is earned rather than automatic.

## Visual system

- Preserve the course's warm cream background, orange accent, and restrained
  academic style.
- Use one hand-drawn putting illustration to establish the scientific setting.
- Keep observed proportions visually distinct from posterior means and 90%
  intervals.
- Reuse the same orange model line and uncertainty grammar across the baseline,
  geometric fit, and external check.
- Build the putting-angle explanation as native vector artwork in
  `Slides/diagrams/golf_geometry.typ` so its labels remain sharp when projected.

## Slide sequence

### 1. Model comparison asks which useful story predicts best

Introduce LOO as a predictive ranking tool, while emphasizing that a model's
scientific usefulness matters alongside a small ELPD difference.

### 2. Two putting datasets let us fit, then genuinely predict

Reveal the original Berry data first and the later Broadie data second. Use the
older data for model building and reserve the newer data as an external check.

### 3. Start simple: logistic regression shows what remains unexplained

Show the familiar two-parameter logistic baseline, its fitted relationship,
and the systematic short- and long-distance mismatch that motivates a more
mechanistic model.

### 4. Geometry turns distance into a success probability

Explain the acceptable aiming angle generated by the ball and cup geometry,
then connect that angle to a single golfer-accuracy parameter.

### 5. One angular-noise parameter fits the original data remarkably well

Show the geometric model against the Berry observations and keep the central
scientific quantity—the angular error scale—visible.

### 6. A trusted model earns a harder test on new data

Carry the fitted model to the Broadie dataset without refitting. Separate
uncertainty in the fitted mean from predictive variation in future counts, and
use remaining mismatch to motivate the next model family.

  posterior predictive check for the Broadie makes.
- Data citations are shown on the relevant slides; the comparison values are
  clearly labeled as illustrative.

# Final model-expansion and active-learning sequence

## Teaching purpose

Close the golf case study by showing how a mechanistic expansion creates a new
computational problem, then compress the remaining model revisions into one
decision-oriented map. Transition from demonstration to active work with the
sleep-deprivation data and a clear statement of what learners will practice.

## Slide sequence

### 1. A putt must have the right direction and the right distance

Redraw the book's angle-and-distance geometry and reveal the direction model,
distance model, and product probability in three stages. Keep both physical
parameters interpretable.

### 2. The expanded model appears to improve fit and interpretability

Show a representative high-density fitted mode against the Broadie data. Mark
the persistent middle-distance mismatch and explicitly withhold posterior
interpretation until diagnostics have been checked.

### 3. Have we sampled the posterior?

Use the trace/distribution figure generated by
`golf/03_angle_and_distance.ipynb`. Reveal the R-hat and ESS failure, then the
conclusion that apparent fit is not yet the relevant question.

### 4. Each failed check suggests the next model—not the final model

Reveal four model-revision cards: Normal discrepancy, distance-dependent logit
noise, proportional noise, and the general lesson of iterative criticism.

### 5. The sleep-deprivation data

Plot all 18 participant trajectories and the daily mean. Show the corrected
study timeline and make the multilevel structure visible before any model is
introduced.

### 6. What we will practice

Reveal three active-learning goals: prior choice, hierarchical modeling, and
responsible use of AI. End with the independence objective.
