# Bioassay example

This directory contains the course bioassay workflow:

- `bioassay.ipynb` — the compact worked example used for teaching and slide figures.

The notebook is intended for Google Colab and includes an **Open in Colab** button. Its setup cell installs the course's tested PyMC, modular ArviZ, and Bambi versions so the analysis remains reproducible when Colab's bundled packages change.
